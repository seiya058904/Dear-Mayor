# Dear Mayor · 小镇，请批示

一张阳光下的书桌，一座认真又有些荒唐的小镇。

**[打开游戏](https://seiya058904.github.io/Dear-Mayor/)** · [迭代说明](docs/CONTENT.md) · [验收记录](docs/QA.md)

![Dear Mayor 实际桌面画面](docs/screenshots/desktop.png)

你是镇长。读完一封信，选择批准、不批准、搁置，或提笔从三项贴合来信的批示中择一。几天之后，钟匠、羊倌、木匠和街坊会把后来发生的事写回来。没有资源面板、得分、任务列表，也没有即时的“正确答案”。

“搁置”表示不回复、不办理，与正式驳回不同；不会将原信放回待办队列。批示可以收起，选中具体方案才提交。每次处理自动保存，刷新后接着当前未完成的信。右下角“重启一季”需确认才替换存档。

## 首版内容

- **116 封不同文书**：12 条故事线各 7 个文书节点（其中 4 个是互斥分支），另有 32 封独立日常来函。首封桥梁请愿保留用户提供的原文，其余 115 封为本版创作。
- 每条故事线实际经历 **4 个阶段**：起始 → 决策分支 → 后续 → 收尾；后续会带上实际选择造成的结果。
- 每封提供 **3 个情境批示**。普通批准、正式拒绝、沉默与批示分别记录。
- **18 个重复发信的人物或机构署名**；另有其他街坊客串。
- 一局走完 **80 封不重复文书、20 个游戏日**；默认每批 4 封。互斥分支需另开一局体验。
- 主体内容结束后进入 **4 种循环日常来函**，携带上一封的处理记忆。这些循环变体不计入 116 封，也不等同于无限原创剧情。

## 本地运行

需要 Node.js 24 与 npm。依赖版本由 `package-lock.json` 固定。

```sh
npm ci
npm run dev
```

开发入口为 `http://127.0.0.1:5173/`。

```sh
npm run check
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

构建产物在 `dist/`。正式构建内含 Service Worker；首次联网完整缓存后可断网刷新与继续游戏。开发服务器不注册离线缓存。所有字体、图像和文书本地随包提供，无在线 AI、账号、外部字体 CDN 或分析 SDK。

## 操作与设备

鼠标、触摸、Tab / Enter / Space 可操作；Escape 收起批示。遵循系统减少动态效果设置。桌面按 1672×941 场景等比显示；手机使用竖版文书和两列按钮，长文随页面滚动。极端长文在桌面纸内滚动。

存档只在当前浏览器、当前站点保存；本地预览与线上站点不共享。清理网站数据会丢失进度。不能读取的存档会尝试保留恢复副本，并明确提示。当前不支持跨设备同步或多标签页同时编辑同一局。

## 部署与素材

`main` 的推送会执行类型检查、引擎测试、生产构建和 Chromium 浏览器测试；全部通过后发布 GitHub Pages。构建使用相对资源路径，支持项目子目录。`build-info.json` 记录产物版本与提交 SHA。

绘本素材来自用户提供的复制包，动态桌面纸面与手机纸面由其衍生。原始下载目录未修改。字体使用 [LXGW WenKai Lite](https://github.com/lxgw/LxgwWenKai-Lite)，遵循随包 [SIL OFL](public/fonts/OFL.txt)。素材记录与生成提示词见 [ASSETS.md](docs/ASSETS.md)。本仓库公开不额外授予未声明素材的再分发许可。

本版是可继续迭代的首发基线；不是参考图的像素级复制，也不是无限内容生成器。
