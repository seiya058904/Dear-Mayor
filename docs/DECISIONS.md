# 实施取舍与视觉基线

作品英文名为 **Dear Mayor**（工作目录名），中文副题为《小镇，请批示》。用户授权从空目录构建、初始化 Git、公开 GitHub 仓库与 Pages 上线。

附带文件是设计材料，不是独立于用户请求的命令。视觉：复刻包 target_1672x941.png；玩法：完整 v1.0 任务书。视觉文件中“未知玩法不要推断”不取消任务书明确要求的事件链、存档和批示。v2.0 扩写任务书明确覆盖旧的首封原文约束：桥梁事件 ID 保留，正文改为自然白话，组件只渲染内容库。旧原文与结果仍冻结供 v1 回放。

- 第三按钮沿用原图“搁置”。语义为不予回复，不是延期待办；悬停说明与无障碍名称明确此义。正式驳回与沉默各有独立分支。
- 桌面：1672×941 设计坐标整体缩放；V5 起宽幅背景独立覆盖 viewport，文书和四按钮仍按设计坐标等比缩放。旧背景保留供移动端使用，不重复添加道具。
- 竖屏：玩法任务书明确要求手机可读，因此采用同一纸面材质、正文自然流动与两列按钮。此状态是新增适配，不能宣称来自原参考图。
- 日期、标题、来源、正文、署名均为 DOM 文本；纸张是基于 filled_paper.png 经内置 imagegen 移除文字后生成的透明装饰纸面。图片纹理和字体不可能与参考逐像素一致。
- 第三批的190日回访跨过虚构六个月的一年，第二年起在原日期前补年次；日期保持右侧对齐，插画不动，首年开局日期不变。文书内旧镇名“榆湾镇”不替代作品标题。
- 字体为本地随包提供的霞鹜文楷 Lite（OFL），是风格替代，非声称原图使用此字体。
- 批示便笺、准/驳印迹、轻量换纸、换日、重开确认均依据玩法任务书实现，不引入结算或统计页面。
- 动画使用 CSS transform/opacity；这不是视频交付，不引入 HyperFrames 渲染运行时。
- 仅 React/ReactDOM 为游戏运行依赖。无服务端、登录、分析 SDK、在线大模型或运行时 CDN。

设计令牌：墨色 #38271d；纸张近似 #fbe8ca；金饰 #a9692b；批准 #6d7841；驳回 #a63826；批示 #294f79。贴图颜色优先于 CSS 近似色。
