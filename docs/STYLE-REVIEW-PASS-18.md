# 润色第18批：按“写信”重写（第三、四批共62封；目录28）

2026-11-05。第17批的修订仍把信写成了“旁白加段子”，读不出这是一个人写给镇长的信。本批回到最基础的逻辑：**这是一封信，写信的人要办一件事。**

## 写法

- 标题：像“桥梁修缮请愿”那样，是一句事由（“请准我挪一挪会客室的灯”），不再是谜语或玩笑。
- 正文：先交代自己是谁或碰到了什么事，再讲清楚想请镇长批什么，最后客气收尾（“烦请您准我动手”“给您添麻烦了”）。信文里仍可留一两句人物自己的小玩笑，但不再靠它来传达请求。
- 体裁：letter 用日常口吻；note 简短；official 与 archive 更正式或像备忘（“现请准许……”“现请确认……”）。
- 批示与结果文字沿用上一版（它们本来就是镇长的批语和之后发生的事），ID、署名、体裁、顺序、调度均不变，0新增节点、0链改动。
